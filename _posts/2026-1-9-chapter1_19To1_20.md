</p>
<p>
And then it means and in short the software cracking process in the end comes to searching for this <code style = "color: chartreuse;">JMP</code> instruction.
</p>
<p>
There are also cases, the program in them checks the protection from time to time,
</p>
<p>
Whether dongle, or license server asked via the internet.
</p>
<p>
Then you have to search for the function that checks the protection,
</p>
<p>

<h1 style="color:#9a3ba6; font-family: 'Press Start 2P', 'system-ui' "><b>1.20 Impossible shutdown practical joke (Windows7)</b></h1>
<img src="/assets/img/Windows7.jpg" alt="Windows7" style="display:block; margin:20px auto; border-radius:12px; max-width:80%;">

<p>
The author explained that he found the function <code style = "color: chartreuse;">ExitWindowsEx()</code> in the <code style = "color: chartreuse;">user32.dll</code> file of Windows 98
</p>
<p>
And then he tried to stop it by modifying its beginning and putting the byte 0xC3 (RETN instruction)
</p>
<p>
Then Windows 98 became impossible to shut down and he also tried it on Windows 7
</p>
<p>
And the function <code style = "color: chartreuse;">ExitWindowsEx()</code> is still present in the user32.dll file
</p>
<p>
And it does the same purpose.
</p>
<p>
The first thing he did was disable Windows File Protection
</p>
<p>
By adding this line in the registry
</p>
<p>
(Because otherwise Windows would restore the modified system files automatically without you noticing):
</p>
